# Portfólio — Nicholas Araújo

Site estático responsivo em HTML, CSS e JavaScript, com fundo preto, acentos roxos/azuis e layout inspirado na referência visual fornecida.

## Visualização local
Extraia o ZIP e abra `index.html` no navegador. Mantenha `style.css`, `script.js` e a pasta `assets/` junto do arquivo HTML.

## Publicação
Envie todos os arquivos desta pasta para a raiz de um repositório GitHub e habilite GitHub Pages em Settings → Pages.

Conteúdo acadêmico e técnico baseado no currículo fornecido. A área de projetos indica explicitamente que projetos próprios serão adicionados quando estiverem prontos.
